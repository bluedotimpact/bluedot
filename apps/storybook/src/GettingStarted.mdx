### Colors

Colour tokens mirror the Figma design-system variables and are used through Tailwind utilities. Pick the **role**, not the hue: the Figma leaf name is the token name (`text/secondary` → `text-secondary`, `accent/primary` → `bg-accent`). Where a surface or border leaf collides with a text leaf, the role prefix stays (`bg-surface-on-dark`, `border-border-on-dark`).

- Text: `text-primary`, `text-secondary`, `text-placeholder`, `text-disabled`, `text-link` (+ `-hover`, `-active`), `text-on-dark`, `text-on-dark-secondary`
- Surface: `bg-canvas` (cream by default, white on bluedot.org), `bg-raised`, `bg-tint` (hover wash), `bg-active` (pressed / selected), `bg-dark`, `bg-surface-on-dark`, `bg-surface-on-dark-subtle`
- Border: `border-subtle`, `border-default`, `border-strong`, `border-border-on-dark`
- Accent (interactive): `bg-accent`, `hover:bg-accent-hover`, `active:bg-accent-active`, `bg-accent-subtle`
- Status: `text-{info|success|warning|error}-fg`, `bg-…-bg`, `border-…-border`, plus `hover:bg-error-fg-hover` for destructive buttons. Never hand-pick a red or green.
- Focus & overlay: `ring-focus`, `bg-scrim`, `bg-overlay-image`

Reach for the raw `bluedot-*` palette (`text-bluedot-navy/60`) only when no role fits.

### Typography

You may use `text-size-` classes for different text sizes, from `text-size-xxs` (12px) for the smallest text to `text-size-4xl` (56px → 72px at md+) for marketing-hero headlines. The `xl`, `2xl`, `3xl` and `4xl` tokens are responsive — they scale up at the `md` breakpoint.

Marketing heros render `<HeroH1>`, which defaults to the `text-size-xl` ramp; a larger size can be passed via `className`.

For convenience we also ship `<H1>` through `<H4>`, `<P>` and `<A>` tags that you can use in your React components. Each one bakes in its own weight, line-height, letter-spacing and colour, so you shouldn't need to pass a `className` for the standard look — reach for the plain tag first.

Need those same styles but for a different tag? Use the `.bluedot-h1`, ..., `.bluedot-h4`, `.bluedot-p` & `.bluedot-a` utility classes.

```jsx
import { H1, H2, H3, H4, P, A, Eyebrow, ModalTitle } from '@bluedot/ui';

<H1>Heading 1</H1>
<div className="bluedot-h1">Title</div> <!-- Same as H1 -->
<H2>Heading 2</H2>
<div className="bluedot-h2">Subtitle</div> <!-- Same as H2 -->
<H3>Heading 3</H3>
<div className="bluedot-h3">Subsubtitle</div> <!-- Same as H3 -->
<H4>Heading 4</H4>
<div className="bluedot-h4">Subsubsubtitle</div> <!-- Same as H4 -->
<P>Paragraph</P>
<div className="bluedot-p">Body</div> <!-- Same as P -->
<A href="#">Link</A>
<span className="bluedot-a">Link</span> <!-- Same as A -->
```

#### Weight, line-height & letter-spacing tokens

Beyond size, the scale defines named tokens for the other three dimensions. Prefer these over arbitrary values (`font-[450]`, `leading-[160%]`, `tracking-[-1px]`).

- **Weight** — the four static Inter cuts: `font-normal` (400), `font-medium` (500), `font-semibold` (600), `font-bold` (700).
- **Line-height** — `leading-tight` (1.1), `leading-snug` (1.25), `leading-normal` (1.4), `leading-relaxed` (1.6).
- **Letter-spacing** — `tracking-tighter` (−0.02em), `tracking-tight` (−0.01em), `tracking-normal` (0), `tracking-wide` (0.04em). Use `em`, not `px`, so tracking scales with font size.

### Border Radius

We prefer two border radius tokens: `rounded-sm` and `rounded-lg`. 

You can use `rounded-` Tailwind CSS utility classes to create rounded corners on your components.

<Unstyled>
  <p className="p-8 max-w-64 bg-canvas rounded-lg border-default border-1">
    <p className="mb-4 text-primary">rounded-lg</p>
    <p className="p-4 max-w-48 bg-dark text-on-dark rounded-sm border-default border-1">
      <p className="text-on-dark">rounded-sm</p>
    </p>
  </p>
</Unstyled>
